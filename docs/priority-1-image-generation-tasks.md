# Priority 1 图片生成任务清单

用途：用于人工复制到图片生成工具，先验证前两篇文章的 6 张配图风格与可用性。

范围：

- `night-tinnitus`
- `cannot-hear-speech`

统一规则：

- 不要生成图片。
- 不要上传 WordPress。
- 不要修改文章正文。
- 图片内尽量不要生成中文文字。
- 图片负责表达场景、情绪、关系和步骤感；中文解释放在网页 `alt`、`caption` 或正文卡片中。
- 推荐尺寸统一为 `1200x675`。

统一风格：

温暖柔和的水彩插画风格，浅色背景，中老年友好，家庭生活感，医疗可信但不过度医疗化，深蓝 / 浅灰 / 米白 / 淡紫点缀，画面简洁克制。

统一 negative prompt：

不要夸张痛苦表情，不要恐怖医学图，不要复杂解剖图，不要强烈红色警告风格，不要营销海报感，不要密集文字，不要错误中文文字，不要过度科技炫光，不要过度卡通儿童风。
